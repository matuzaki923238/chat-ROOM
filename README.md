# メッセージアプリ

チームで制作している、LINEのようなメッセージアプリです。

## 動かし方

`index.html` をブラウザで開くと、ログイン画面が表示されます。

## フォルダ構成

| 場所 | 内容 |
|---|---|
| `index.html` | ログイン画面 |
| `home.html` | ホーム画面（今は確認用の仮ページ） |
| `css/` | 見た目（デザイン） |
| `js/` | 動き（入力チェックなど） |
| `docs/` | 設計図と解説 |

## 資料

- [画面遷移図](docs/画面遷移図.md)
- [ログイン画面の解説](docs/ログイン画面.md)

## 作業の進め方

1. 作業前に最新版を取り込む（Pull）
2. `main` を直接変えず、作業用のブランチを作る
3. 変更をコミットしてプッシュし、プルリクエストを出す
4. メンバーに確認してもらってから `main` に取り込む
